# ChargeCast Web

React + TypeScript + Vite frontend for the ChargeCast research dashboard.

## Run

```bash
cd chargecast-web
npm install
npm run dev          # http://localhost:5173
```

The backend must be running on <http://localhost:8000>. Copy `.env.example` to
`.env.local` to point elsewhere:

```
VITE_API_URL=http://localhost:8000
```

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Dev server on 5173 |
| `npm run build` | Typecheck then production build to `dist/` |
| `npm run preview` | Serve the built bundle |
| `npm run lint` | ESLint, zero warnings tolerated |
| `npm run typecheck` | `tsc --noEmit` |

## Stack

React 18, TypeScript (strict, `noUnusedLocals`, `noUnusedParameters`,
`@typescript-eslint/no-explicit-any` as an error), Vite 6, Tailwind CSS 3,
Recharts, Framer Motion, Lucide, and shadcn-style primitives built on
`clsx` + `tailwind-merge` + `class-variance-authority`.

**On shadcn/ui:** the primitives in `src/components/ui/` follow the shadcn
pattern (headless components, `cn()` merge helper, `cva` variants) and were
written directly rather than generated by the CLI, which is interactive and
would pull in Radix packages this dashboard does not need.

**On Plotly:** not used. The heatmap and confusion matrix are drawn as CSS grid
and SVG, which is lighter than a ~3 MB plotting dependency for two fixed-shape
visuals and keeps the chart chunk to ~112 kB gzipped.

## Layout

```
src/
├── api/          client.ts (fetch + error type), endpoints.ts (fixed path list)
├── charts/       theme.ts and one file per visual
├── components/   shared presentation + ui/ primitives
├── hooks/        useApi (cached fetch), useHealth (API status polling)
├── layouts/      AppShell — sidebar, top bar, footer
├── lib/          cn() and display formatting
├── pages/        one file per route, lazy-loaded
└── types/        api.ts — response types for every endpoint
```

## Data handling

* Every page routes its fetches through `QueryBoundary`, which handles loading,
  transport failure and the API's `available: false` contract in one place. A
  chart is never rendered without data behind it.
* `EmptyState` shows the artefact label, expected path, and the expected and
  detected columns when a schema does not match.
* The API health indicator reflects a real `/api/health` response; it is never
  assumed.
* No `Math.random()`, faker, mock or placeholder data exists anywhere in
  `src/`.

## Performance

Pages are lazy-loaded and the vendor chunks are split (`react`, `charts`,
`motion`). API responses are cached per path and parameter set for the session.
The demand ribbon requests a downsampled series rather than every stored hour.
